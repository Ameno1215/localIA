Local AI Platform

Our local AI platform

Self-hosted LLM platform for a coding assistant, an internal-standards search (RAG) and a web chat. It has two tiers: an x86 application server for access, apps and data, and an NVIDIA DGX Spark dedicated to inference. Everything is deployed with Docker Compose and runs offline once the models are downloaded.

Security

  • Two ports exposed on the server (443, 8443). The Spark only accepts port 8000 from the server's IP, plus SSH.
  • One API key per user, with quotas and usage tracking. Revoking a key cuts that user's access immediately.
  • The MCP server only offers read-only document search. No file or shell tools are reachable from the network.
  • Secrets (master key, DB password, tokens) live in a .env file with mode 600 and are never committed.

Operations

  • Runs fully offline (HF_HUB_OFFLINE=1). Internet is only needed to pull images and model weights, or they can come from a transfer disk.
  • All persistent data lives in one data directory per machine, so a backup is one folder.
  • The model is swapped through a profile in config/modeles-spark/. Clients keep the same model name.
  • Health checks are a control panel on port 7000 (localhost/SSH) and a check script.
