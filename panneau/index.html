Comment utiliser

Toutes les commandes se lancent dans un terminal, depuis le dossier ~/Documents/IA locale.

Coder avec l'agent OpenCode (recommandé)

1. Lance le mode agent de code ci-dessus et attends que vllm soit « En marche ».

2. Dans un terminal, va dans ton projet (de préférence un dépôt git propre), copie les consignes de l'agent une fois, puis lance-le :

cd mon-projet
cp ~/Documents/IA\ locale/clients/AGENTS.md .
opencode

3. Écris ta demande. L'agent montre chaque modification et chaque commande, et attend ton accord. Enchaîne ensuite tes demandes dans la même conversation.

Raccourcis : /undo annule la dernière modification, /new démarre une nouvelle conversation, /compact libère du contexte, Tab passe en mode plan (réflexion sans modification).

En une seule commande, sans interface (-c poursuit la conversation précédente) :

opencode run "Ajoute un test pour la fonction verifier"
Avec un petit modèle : une demande précise à la fois, nomme les fichiers, demande de lancer les tests, et vérifie toujours git diff.

Installer OpenCode sur un autre poste : ./scripts/installer-opencode.sh (voir le guide, section 4).

Discuter avec le modèle (navigateur)

1. Lance le mode chat ou Tout démarrer ci-dessus. vLLM met environ 2 minutes à être prêt.

2. Ouvre http://localhost:3000. Le premier compte créé devient administrateur.

3. Pour que le chat puisse chercher dans les normes : Réglages admin → Outils externes → ajouter le serveur MCP http://mcp-docs:9901/mcp.

Ajouter tes normes et documents internes (RAG)

Dépose tes PDF, DOCX, MD ou TXT dans le dossier affiché dans la section Documents ci-dessus, puis clique sur Indexer les nouveautés (mcp-docs doit tourner). Seuls les fichiers modifiés sont réindexés. Les tableaux Word sont convertis, et les images (tableaux, schémas, pages scannées) sont transcrites par le modèle s'il lit les images (modèle par défaut, VL). En ligne de commande :

docker compose exec mcp-docs python ingest.py && docker compose restart mcp-docs

Pour tout réindexer :

docker compose exec mcp-docs python ingest.py --reset
Créer un accès pour un collègue

Chaque personne a sa clé (2 requêtes en parallèle, 60 par minute). Elle sert dans Open WebUI et OpenCode.

./scripts/creer-cle-utilisateur.sh prenom.nom
Entraîner le modèle sur les normes (LoRA)

1. Génère le jeu de questions/réponses à partir des docs indexés. Relis-en un échantillon ensuite.

source .env && docker compose exec -e LITELLM_KEY=$LITELLM_MASTER_KEY mcp-docs python /finetune/generer_dataset.py

2. Passe en mode fine-tuning (libère le GPU), puis lance l'entraînement :

python3 -m venv .venv-finetune && .venv-finetune/bin/pip install -r finetune/requirements.txt
.venv-finetune/bin/python finetune/entrainer_lora.py

3. Dans .env, décommente VLLM_LORA_ARGS, puis redémarre vLLM. Le modèle normes devient disponible.

Le fine-tuning apprend le style et le vocabulaire, pas les règles exactes. La source de vérité reste le RAG.
